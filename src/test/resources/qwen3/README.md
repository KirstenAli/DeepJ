# Qwen3 verification fixtures

`float32`, `float16`, and `bfloat16` contain tiny, randomly initialized Qwen3 checkpoints and reference outputs and
gradients generated by `src/test/python/qwen3_reference.py` with PyTorch 2.8.0 and Transformers 4.51.3, seed 417.
They use a deliberately independent head width: hidden width 12, four query heads, and head width four.
After storing each checkpoint, the reference model converts the quantized parameters to FLOAT32 for arithmetic.
No pretrained model weights are included in these fixtures.

`chat-golden.json` and `tokenizer-golden.json` are generated by `src/test/python/qwen3_tokenizer_reference.py` using
the official [Qwen3-1.7B tokenizer](https://huggingface.co/Qwen/Qwen3-1.7B/tree/70d244cc86ccca08cf5af4e1e306ecf908b1ad5e).
They cover text-chat formatting and 214 strings including seeded Unicode cases. The full tokenizer asset is supplied
locally for the optional golden test and is not bundled with DeepJ. Run Prettier on regenerated JSON fixtures.

The [Qwen model assets](https://huggingface.co/Qwen/Qwen3-1.7B/blob/main/LICENSE) and
[Transformers reference](https://github.com/huggingface/transformers/blob/v4.51.3/LICENSE) are Apache 2.0 licensed.
