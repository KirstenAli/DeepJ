Modified for Java and DeepJ tensor execution by Kirsten Ali, 2026.
The adaptations use DeepJ tensors, automatic differentiation, memory scopes,
checkpoint readers, and CPU/Metal backends. Python and PyTorch are not part
of the inference runtime. The Java implementation streams Transformer blocks
for inference and exports animation through Java ImageIO.
