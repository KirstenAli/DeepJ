DeepJ is a Java neural network library for building, training, and running models. N-dimensional tensors, automatic differentiation, composable layers, and CPU/Metal backend operations form one shared foundation for feed-forward, convolutional, recurrent, autoencoder, and Transformer networks.

This reference documents DeepJ 0.13.0-alpha, including the nn package. FNN is in io.github.kirstenali.deepj.nn. Match your dependency version to the API reference.

Start with the documentation index for network, training, persistence, and backend guides. Decoder language-model APIs, tokenization, and chat tools are specialist parts of the library.
