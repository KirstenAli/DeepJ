Supported networks

Choose a network. Keep the same foundation.

Compose layers, calculate gradients, and train across network families with DeepJ tensors, parameters, and optimizers.

01

Feed-forward networks

FNN, with configurable hidden layers and activations for classification and regression.

02

Convolutional networks

Conv1D, Conv2D, max/average pooling, and global average pooling for channel-first inputs.

03

Recurrent networks

RNN, GRU, and LSTM, with explicit hidden state and per-sample sequence lengths.

04

Autoencoders

Compose an encoder and decoder, train a reconstruction objective, and access the latent representation separately.

05

Transformer encoders

Bidirectional attention, padding masks, pre-normalized blocks, and masked mean pooling.

06

Decoder Transformers

DeepJ Origin, Orbit, Prism, Nova, and Loop, with causal language-model training and text generation.

These network families use DeepJ layers, parameters, tensors, and autograd.

Core library

One foundation for every network.

Tensors, gradients, composition, training, and execution belong to the library as a whole.

01

N-dimensional tensors

One shape-aware tensor API for vectors, matrices, images, and sequences, including views and broadcasting.

02

Automatic differentiation

Record tensor operations and propagate first-order gradients through the same CPU/Metal backend.

03

Composable layers

Combine existing and new layers with Sequential, activation adapters, dropout, and BatchNorm.

04

Training utilities

Supervised matrix and ND batching, differentiable losses, AdamW, and explicit training/evaluation mode.

05

Saving and loading

Store network parameters and persistent buffers. Language-model files and resumable checkpoints have separate contracts.

06

CPU and optional Metal

Use Java CPU execution or select Metal on supported Apple Silicon. Network arithmetic shares these backend operations.

Install

Bring DeepJ to your Java project.

JDK 20 or newer is required. Version 0.13.0-alpha includes the neural-network APIs described here, with FNN in the nn package.

Add the Maven dependency to your project, or build DeepJ from source. The documentation covers the shared network, training, persistence, and execution APIs.

Read the release notes →
Maven0.13.0-alpha
<dependency>
    <groupId>io.github.kirstenali</groupId>
    <artifactId>deepj</artifactId>
    <version>0.13.0-alpha</version>
</dependency>
