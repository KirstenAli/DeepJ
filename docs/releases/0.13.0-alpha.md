# DeepJ 0.13.0-alpha

Status: prepared for release; Maven Central publication is pending.

DeepJ is a Java neural network library for building, training, and running models.
This release expands its neural-network APIs on the existing tensor, autograd,
parameter, optimizer, and CPU/Metal backend foundation.

## What changed

- Composable `Sequential` and `Module` APIs, an MLP adapter over `FNN`, activation
  adapters, flattening/reshaping, dropout, and BatchNorm.
- `Conv1D` and `Conv2D`, max/average pooling, and global average pooling for CNNs.
- RNN, GRU, and LSTM cells and sequence layers, with explicit state and per-sample lengths.
- Composable autoencoders with separate encoder and decoder access.
- Bidirectional Transformer encoders with padding masks and masked mean pooling.
- ND supervised minibatching through the existing `Trainer`, losses, and optimizers.
- Versioned network weight archives for parameters and persistent buffers.
- README, website, guides, and API documentation organized around neural networks,
  with language-model tools presented in their own section.

All new network arithmetic uses DeepJ tensors and backend operations. Convolution
uses gathered windows and matrix products; recurrence uses projections and tensor
activations. Concatenation and stacking register a slicing rule with existing autograd.

## Compatibility

Existing Java/native implementations and language-model checkpoint formats are
unchanged by the network additions. No model weights are retrained or converted.
Frisky 90M remains a Prism decoder model. The older TinyStories checkpoint still
requires its explicit architecture configuration when loading.

The `NetworkWeights` archive is separate from language-model `.dj` files. It restores
parameters and persistent buffers into an already constructed architecture; keep
optimizer, recurrent, dropout RNG, and other training state separately as needed.

Optional compact storage uses the existing `ParameterFactory` policy and FLOAT32
gradients. It does not imply a new fused convolution kernel or a throughput guarantee.

## Verification

The network implementation commit passed the full macOS CPU/Metal/desktop profile,
including 36 new Metal parity cases across FLOAT32, FLOAT16, and BFLOAT16, with zero
skips in those cases. Tests also cover independent equations, finite-difference
input/parameter/state gradients, masks, training, and exact weight/buffer restoration.
The final release-preparation commit must pass the same required checks before use.

## Distribution and publication

JDK 20 or newer is required. Coordinates for this prepared release are
`io.github.kirstenali:deepj:0.13.0-alpha`; the intended tag is `v0.13.0-alpha`.
The currently published Maven Central version is `0.12.0-alpha` until publication.

Validate the source with `mvn clean verify`. On supported Apple Silicon macOS with a
Metal device and desktop session, use `mvn clean verify -Pfull-coverage`.

The maintainer performs the final signed publication from the approved release source:

```sh
mvn clean deploy -Pcentral-release
```

That command requires the maintainer's configured Central credentials and signing key.
No Maven Central deployment is performed as part of this release preparation.
