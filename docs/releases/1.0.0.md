# DeepJ 1.0.0

DeepJ is an open-source Java neural network library for building, training, and
running models on CPU and Apple Metal. Version 1.0.0 is available on Maven Central:

```xml
<dependency>
    <groupId>io.github.kirstenali</groupId>
    <artifactId>deepj</artifactId>
    <version>1.0.0</version>
</dependency>
```

JDK 20 or newer is required.

## Neural networks and execution

- N-dimensional tensors, automatic differentiation, FP32/FP16/BF16 storage,
  shared CPU/Metal operations, optimizers, and model persistence.
- Feed-forward, convolutional, recurrent, autoencoder, and Transformer networks.
- Optional distributed training across CPU and Metal workers.
- Optional ONNX import and execution through DeepJ tensors and autograd.

## Models and desktop tools

- Qwen3-1.7B and Gemma 2 pretrained chat, alongside DeepJ decoder models.
- Qwen3 Thinking and Agent mode in the desktop UI and CLI, with terminal-command approval.
- `--thinking` and `/set thinking on|off` in terminal chat and Agent mode.
- SANA-Sprint image generation and PNG saving.
- SANA-Video generation, playback, and MP4 saving.
- A shared desktop app for chat, agents, images, and videos.
- One downloadable desktop JAR for Apple Silicon macOS and Windows x64, with JavaFX bundled.
- Auto, CPU, and Metal selection in Settings, saved for the next app launch.
- Canvas-backed image previews, with original PNG downloads preserved.
- Chat and Agent responses default to 2,048 generated tokens.

The README leads with desktop Qwen chat using BF16 weights and activations, and
links to CLI commands. Frisky 90M remains available as a model trained from scratch
with DeepJ. See the [guides](../README.md) and [performance measurements](../performance.md).

## Downloads

The [GitHub release](https://github.com/KirstenAli/DeepJ/releases/tag/v1.0.0)
provides the library, CLI, source and Javadoc archives. The optional ONNX and
distributed artifacts use version 1.0.0 and depend on DeepJ 1.0.0.

Download the [desktop JAR](https://github.com/KirstenAli/DeepJ/releases/download/v1.0.0/deepj-desktop.jar)
for Apple Silicon macOS or Windows x64 and follow the [desktop guide](../desktop.md). The GitHub
assets include the latest sampler correctness fixes and bounded video inference
improvements documented in the performance reports.

Model weights are downloaded separately; the model guides link to their checkpoints.

See [release verification](1.0.0-validation.md) for CPU, Metal, desktop, ONNX,
distributed and real Qwen3 CLI checks.
