# DeepJ 0.12.0-alpha

## What changed

- One N-dimensional tensor API for scalars, vectors, matrices and batched arrays,
  including broadcasting, strided views and first-order autograd on CPU and Metal.
- FLOAT32 remains the default. Optional FLOAT16 and BFLOAT16 use genuine two-byte
  storage, explicit promotion and casting, and FLOAT32 gradients and optimizer state.
- Compact-input fused attention and broader supported MPS matrix routing. Eligible
  BFLOAT16 and reverse mixed FLOAT16/FLOAT32 products use scoped, lossless GPU
  conversions; products with excessive conversion cost retain the compact kernel.
  FLOAT32-only MPS routing is unchanged. Smaller storage does not guarantee faster
  training or halve total training memory.
- Opt-in rolling KV-cache generation for Orbit, Prism, Nova and Loop, available
  through the Java API, desktop UI and CLI. It keeps decoding incremental after
  eviction, with different attention semantics beyond the context window.
- Lower host allocation and tighter device-buffer ownership, including lazy gradient
  zeros, optimizer batching and safer shared tensor lifetimes.
- Updated tensor, training, generation and migration documentation, plus the enforced
  [coding and regression standards](../quality-and-regression.md).

## Compatibility

Existing FLOAT32 checkpoints remain loadable. Typed exports preserve their dtype and
FLOAT32 optimizer master state. No user checkpoint is automatically converted.
Matrix constructors remain available, but code using direct `.rows`, `.cols` or `.data`
fields must follow the [tensor migration guide](../tensors.md#migrating-matrix-only-code).

Generation still defaults to context-window rebuilding. Enable rolling mode explicitly;
it does not extend a checkpoint's trained context capability. Prompt formatting remains
shared by the Java chat loader, desktop UI and CLI.

## Distribution

JDK 20 or newer is required. Maven coordinates are
`io.github.kirstenali:deepj:0.12.0-alpha`. Maven Central publication is a separate manual
maintainer step; until it completes, build tag `v0.12.0-alpha` from source or use the
standalone CLI attached to the GitHub prerelease.

```sh
mvn clean verify -Pcli
java --enable-native-access=ALL-UNNAMED -jar target/deepj-cli.jar chat ./frisky-90m
```

Add `--backend cpu` for CPU-only execution. This release does not change Frisky's weights
or claim a model-quality improvement.
